# Microsoft Store localized listing text

`listings.json` is the Windows-specific draft text source for nine listing identities: `en-US`, `en-CA`, `es-ES`, `fr-FR`, `fr-CA`, `de-DE`, `zh-CN`, `pt-BR` and `ja-JP`. It follows the Play metadata's `schemaVersion: 1` and `locales` shape. Seven records contain wording; `en-CA` uses only `{ "copyFrom": "en-US" }` and `fr-CA` uses only `{ "copyFrom": "fr-FR" }`. Resolve these copies when exporting, keeping both Canadian listing identities.

Each wording record contains `title` (always `Persistent`), `fullDescription`, `shortDescription`, `features`, `keywords`, `heroHeadline`, `heroSubline` and `screenshotCaptions`. These are semantic source fields, not Microsoft CSV field names or IDs. Release notes are not listing text: they are per version, in `release-notes/desktop-<version>[.<identity>].md`, and `store-publish` sends them to every listing locale (LIST-10).

| Text                | Limit                                                                                           |
| ------------------- | ----------------------------------------------------------------------------------------------- |
| Full description    | 4,000 characters                                                                                |
| Short description   | 270 characters                                                                                  |
| Features            | Up to 20, each up to 200 characters                                                             |
| Keywords            | Up to 7, each up to 40 characters, at most 21 words combined                                    |
| Hero headline       | Fits the generated first screenshot; `devkit-store-hero` names a locale whose headline does not |
| Screenshot captions | Exactly one per desktop image (the hero and four captures), in order, each up to 200 characters |

The text leads with the product tagline, "Reminders that return until confirmed.", and describes the Windows tray app with notifications that return until confirmed. The desktop limit is one neutral sentence (alerts run while Persistent is open and the PC is awake) with a pointer to the free Android app for alarms that ring offline or with the app closed; it is not framed as a list of shortcomings. The widget is "Upcoming widget for Windows 11". Languages are one sentence naming the seven languages; language, date format, clock and time zone stay separate, and user-authored text is never translated. The language-change audio/menu-reset tradeoff is included in every release-note wording. Privacy copy states no ads, tracking or third-party analytics and discloses the service's own aggregate usage statistics, replacing the inaccurate blanket claim of no analytics.

The first image is the generated hero (D-123): its headline is the first sentence of each locale's short description, and its subline, also its caption, comes from the description's opening (view, snooze and confirm on the same account as the web and Android), so it claims nothing the listing does not. The en-US headline and subline are approved; the other locales' are draft translations awaiting native review. The other captions describe the actual [four Windows captures](README.md), preserving Current, checklist reading view, synthetic vitamin editor and assigned-task progress order. Each locale's screenshots show Windows and the app in that language. This draft does not translate legal documents or constitute native-speaker review.
All captions describe the actual [four Windows captures](README.md) as benefits, preserving Current, checklist reading view, vitamin editor and assigned-task progress order; `manifest.json` carries the same en-US captions. The en-US listing does not mention the English interface (copy review, November 24, 2026). Each locale's description and screenshots match its language, so no listing mentions an English interface. Screenshot image files, URLs and ordering are unchanged. This draft does not translate legal documents or constitute native-speaker review.
