Persistent のアイコンがどのサイズでも鮮明になり、明るいタスクバー用のデザインも加わりました。
「このアプリについて」に、ソースコード、プライバシー、サポート、ライセンス、サード パーティに関する通知、ログ フォルダーをまとめました。
サインイン前は、設定ボタン付きの通常のウィンドウで開きます。サインイン後はトレイのパネルに切り替わります。
時刻の形式を自分で選んでいない場合、Windows の時計の 12/24 時間表示に従います。
「その他のアプリ」が選択した言語で表示されるようになりました。
発行元が Dynamic Solutions (CA) と表示されるようになりました。
安全のため、パネル内のリンクは安全な接続 (https) の場合のみブラウザーで開きます。
