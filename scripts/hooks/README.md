# Agent hooks

Claude Code hooks registered in `.claude/settings.json`. They guide an agent during a session; anything that must never be committed belongs in a git hook instead (AI-11 and HYG-10 in the shared standards).

| Hook | Runs on | Blocks | Do instead |
| --- | --- | --- | --- |
| `generated-file-guard.mjs` | `PreToolUse` for `Edit`, `MultiEdit`, `Write` and `NotebookEdit` | Editing a file whose header says it is generated or not to be edited by hand, or anything under a directory listed in `generated-file-guard.json` | Change the generator or its source, then regenerate. Shell commands, including the regeneration itself, are not inspected. |

`generated-file-guard.json` lists this repo's generated directories:

- `apps/mobile/android`: the Capacitor Android project, regenerated by `npm run android:prepare` from `apps/mobile/android-plugin/` and `apps/mobile/scripts/setup-android.mjs`. Edits there are lost on the next regeneration.

The header check currently matches one tracked file, `apps/api/prisma/migrations/migration_lock.toml`, which Prisma rewrites itself.

The script is written by devkit (`devkit-init`) and is the same in every app; this repo owns only `generated-file-guard.json` and this README. Files devkit generates carry a "Generated by devkit" header, so the guard covers them too. If the guard itself fails, it reports a message and lets the edit proceed rather than blocking all editing. Its tests are in `generated-file-guard.test.ts` and run with `npm test`.
